# Goliath Web

Next.js app for the Goliath frontend (query → agent research → narrated report).

## Run

```bash
cd web
pnpm install
pnpm dev        # http://localhost:3000
```

No backend needed: with `NEXT_PUBLIC_API_BASE_URL` unset, `src/lib/api.ts`
serves everything from mock data (`src/lib/mock/mock-run.ts`), including a
replayed 18-second "live" research run. To hit the real backend, copy
`.env.example` → `.env.local` and set the URL (assumed `http://localhost:8000`).

```txt
src/lib/api.ts               API client with automatic mock fallback

src/app/reports/             /reports         Marc   — issue #3 (report list)

src/components/agents/       shared AgentOrb (Persona wrapper)
src/components/orchestrator/ Felipe's components
src/components/presentation/ Marc's components
src/components/reports/      Marc's components
src/components/ai-elements/  vendored AI Elements (Persona orb)
```

## Key pieces

- **Agent orbs** — `src/components/agents/agent-orb.tsx` wraps the
  [AI Elements Persona](https://elements.ai-sdk.dev/components/persona)
  (Rive/WebGL2 animated orb). Map `AgentPlan.status` → orb animation via the
  `agent` prop; six visual variants are assigned by agent index. The .riv
  animations stream from a Vercel blob URL, so demo needs network.
- **Sim components** — [simstudioai/sim](https://github.com/simstudioai/sim)
  is our pattern/component source (chat layout, agent UI ideas). Cherry-pick
  UI code from `apps/sim` as needed; do NOT adopt its stack (Bun, Postgres,
  Better Auth, Trigger.dev). We stay a plain Next.js + mock/HTTP app.
- **ElevenLabs** — audio is generated by the backend; the frontend only plays
  `PresentationSegment.audioUrl`. Browsers block autoplay with sound, so the
  presentation must start from a user click ("Start briefing" button).
